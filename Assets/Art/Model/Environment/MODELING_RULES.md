# モデリング規約

対象ディレクトリ: Assets/Art/Model/Environment/
最終更新: 2026-09-23

## 用途とスタイル

- 用途: アクションゲーム用ステージ（夕暮れの遺跡アリーナ）の環境アセット
- スタイル: ローポリ・トゥーン（`Sandbox/Toon` シェーダーで単色塗り＋アウトライン）
- 寸法方針: 実寸準拠（キャラクター身長 約1.7m を基準）

## 権利方針

- 外部アセットのDL: 使用しない
- AI 3D生成: 使用しない
- 生成手段: Blender Python によるゼロからの幾何生成のみ（`Source~/Scripts/`）
- 実在意匠・商標・ロゴ・紋章: 混入させない（旗・布は無地）
- 実在の遺跡・建築物の再現はしない。一般的な「石柱・アーチ・壁」の様式レベルに留める

## ポリゴン予算

1パーツ上限: 1500 三角ポリゴン（背景用の大型パーツのみ 3000）

| 区分 | 目安 |
|---|---|
| 小物（木箱・樽・岩） | 〜200 |
| 建築（柱・壁・アーチ・階段） | 〜600 |
| 床・地面 | 〜1500 |
| 背景（崖・岩山） | 〜3000 |

## ディテール封印ルール

作らないもの:
- 面取り（ベベル）。角は立てたまま
- 反復ディテール（石積みの目地・木目・板の継ぎ目）
- 装飾彫刻・模様の凹凸・文字・紋章
- 可動部・内部構造

シェーダー / マテリアルで表現するもの:
- 石の色むら、目地、苔 → マテリアルスロットの塗り分けで表現する。面を細かく割らない

作ってよいもの:
- 曲面は 8 分割まで（柱・樽・篝火台）。岩は凸包による多面体
- 折れ・欠けなどシルエットに効く破損形状
- 板状のもの（布）は 0.04m の厚みを持たせる

## グリッドと寸法

- 単位: Blender 1 unit = 1 m、Z-up
- グリッド単位 G = 1.0 m（配置はシーン側で自由に行うため、タイル化はしない）

## 原点・ピボット

| パーツ種別 | 原点位置 |
|---|---|
| すべて（単体オブジェクト） | 底面中心 |

接地面は Z=0 に揃える。形状は原点基準の座標で直接生成し、生成後の原点移動はしない。

## 命名規約

`Ruin_<カテゴリ>_<名称>_<バリエーション>`

カテゴリ一覧: Floor / Terrain / Stair / Pillar / Arch / Wall / Prop / Rock / Cliff

バリエーション語彙: `Straight` / `BrokenA` `BrokenB` / `A` `B` `C`

オブジェクト名・メッシュデータ名・ファイル名はすべて一致させる。

## マテリアルスロット

全パーツ共通の 4 スロット。Unity 側では FBX ごとにマテリアルを Remap して色を決める。

| スロット | 用途 |
|---|---|
| M_Base | 本体（石・木・地面など） |
| M_Accent | 色を変えたい面（石の上面・苔・布・結晶） |
| M_Emit | 発光させる面（炎） |
| M_Struct | 骨格・枠・金具（台座・鉄帯・枠材・棒） |

## 書き出し

- 形式: FBX（`bake_space_transform=True`, `axis_forward='-Z'`, `axis_up='Y'`, `mesh_smooth_type='FACE'`, 三角化あり）
- 対象エンジン: Unity 6（URP）
- 生成スクリプト: `Source~/Scripts/`（`envlib.py` が共通処理、`build_all.py` が全パーツ生成）
- 作業用 .blend: `Source~/BlendFile/`
- 書き出し先: `Assets/Art/Model/Environment/`
- `Source~` は末尾 `~` により Unity のインポート対象外
